Week 1 - Concepts
Project: Community Blog Website (Green Leaf Gardening Club)

1. Static vs. Dynamic Websites
------------------------------
A static website is made of files (HTML, CSS, images) that are stored on
a server and sent to the browser exactly as they are. Every visitor sees
the same page. To change the content, you have to edit the files by hand.
Examples: a personal portfolio, a simple club website like this project.

A dynamic website creates its pages when someone visits. It usually uses
a server-side language (like PHP, Python or Node.js) and a database. The
page can be different for each visitor, for example after logging in.
Examples: Facebook, online shops, YouTube.

Static sites are simple, fast and cheap to host. Dynamic sites can do more
(logins, comments, search) but are harder to build and maintain.

2. The Role of HTML, CSS and JavaScript in a Blog
-------------------------------------------------
- HTML (HyperText Markup Language) is the structure and content of the
  page: headings, paragraphs, lists, links, images and tables. In a blog,
  HTML holds the post titles, the text of each post and the menu.

- CSS (Cascading Style Sheets) is the design of the page: colors, fonts,
  spacing and layout. In a blog, CSS makes the posts easy to read and
  gives every page the same look.

- JavaScript (JS) adds behavior and interaction: things that happen when
  the user clicks or types. In a blog, JS could be used for a dark mode
  button, a search box or a "like" button.

A simple way to remember it:
HTML = the skeleton, CSS = the clothes, JavaScript = the movement.

3. Purpose of Folder Organization
---------------------------------
Putting files in clear folders makes the project easy to understand and
easy to grow:
- images/  holds all pictures (logo, post photos).
- css/     holds the style sheets.
- docs/    holds documents about the project, like this file.

Good organization helps us find files quickly, keeps links between files
simple (for example images/logo.svg), avoids a messy main folder, and
makes it easier for other people (or a teacher) to work with the project.
