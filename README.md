# Community Blog Website - Green Leaf Gardening Club

A simple static, multi-page blog website for a fictional gardening club.
Made with HTML and CSS only (no JavaScript, no database).

## Pages

| Page | What it shows |
|------|---------------|
| `index.html` | Home / welcome page |
| `posts.html` | Blog posts with images |
| `contact.html` | Meeting place and a table of contact channels |

## Folder Structure

```
project-blog/
├── index.html
├── posts.html
├── contact.html
├── css/
│   └── style.css      (colors, fonts and spacing)
├── images/            (logo and post pictures)
└── docs/
    └── concepts.txt   (Week 1 concepts)
```

## How to Run

1. Download or clone this repository:
   `git clone https://github.com/vlirv/Week1-6216.git`
2. Open the `project-blog` folder.
3. Double-click `index.html` to open it in your browser.

No installation is needed.

## What Each Week Added

- **Week 1:** folder structure and `docs/concepts.txt`.
- **Week 2:** three HTML pages with headings, paragraphs, lists and links.
- **Week 3:** images, a contact table, semantic tags
  (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`) and CSS styling.
